# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the
work. Harassment of any kind is not tolerated.

Report unacceptable behavior to the maintainer at mehran@memoyad.com. Reports are handled
confidentially.
